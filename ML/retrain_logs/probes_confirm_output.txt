  PART 2  --  IS THE HOST MEMORY HELPING OR HURTING?
==============================================================================
  ip_permuted scrambles the keys the memory is read by, so its gain was
  really a hypothesis about the memory. Resetting before every window
  removes cross-window state outright and tests it directly.

  variant                   BENIGN  Volumetr  PortScan  BruteFor    Botnet    MACRO    delta
  val: memory OFF           0.9987    1.0000    0.9875    0.0000    0.0246   0.6021  +0.0444
  test: memory OFF          0.9980    0.9840    0.3133    0.0000    0.0000   0.5738  +0.0188

  A positive delta here means the memory module -- a headline piece of
  this architecture -- is COSTING you accuracy on this dataset. That is
  a reportable negative result, not something to hide. A near-zero delta
  means the memory is inert and the ip_permuted gain came from somewhere
  else, in which case do not blame the memory in the write-up.
