GraphSentinel -- the live loop, run once on real Open vSwitch flows
====================================================================

WHAT THIS IS
  Real traffic between Mininet hosts, through a real OVS bridge, polled by the
  backend's own monitor through the project's own enforcement daemon:
    OVS (s1) -> enforcement_daemon.py `ovs-ofctl dump-flows s1` -> flow_parser
    -> monitor -> provenance gate -> v2 client -> inference service -> rules
    accepted and logged by the backend.
  The `data_source: ovs` tag on every flow was set by flow_parser from the dump
  text. Nothing was tagged by hand and the provenance gate was not changed.

ROUTE
  Route B, local, no Docker. NOT Colab and NOT a replayed capture: the backend
  polled a live switch every 5 s for the whole run.
    WSL2 Ubuntu 26.04.1, kernel 6.18.33.2-microsoft-standard-WSL2
    Open vSwitch 3.7.1, kernel datapath (openvswitch module loaded), Mininet 2.3.0
    topology: mininet/topologies/base_topology_headless.py, unmodified
      (10 hosts 10.0.0.1-10, one switch s1, fail_mode secure, controller
       ovs-testcontroller via Mininet's OVSController -- it installs one
       exact-match flow per conversation, idle_timeout 60)
    daemon: backend/scripts/enforcement_daemon.py, unmodified, in WSL as root,
      127.0.0.1:50051, reached from Windows through WSL2 localhost forwarding
    backend and inference service: the two uvicorn processes of RUN_GUIDE.md
      section 5, on Windows, Python 3.10.10, torch 2.13.0+cpu. No Ganache, no
      frontend. ENFORCEMENT_MODE=simulated, THREAT_THRESHOLD=0.75,
      DEMO_FALLBACK_FLOWS=false, GS2_ENABLED=true.
    backend started with --log-config so that INFO lines from its own
      `graphsentinel.*` loggers are printed. Under the default start they are
      not: no handler is configured for them and only WARNING and above show.

TWO RUNS, SAME TRAFFIC SCRIPT
  Run 1 logged rule COUNTS only; the monitor keeps nothing else of a window.
  So one logging change was made (analysis_pipeline_v2.py: one line per rule
  and one per scored window) and the run repeated. Run 2 is the one analysed.
  Both are given below. The two runs are not a variance estimate.

MEMORY
  3,930 MB machine. Free physical memory was between 123 and 643 MB during the
  runs, with Windows memory compression active. The inference service
  segfaulted once at start (exit 139) with 344 MB of virtual memory free, and
  started after the WSL page cache was dropped. NO TIMING in this file means
  anything.
